Desarrollo de un prototipo con Docker, API y bases de datos
Desarrollo de un prototipo de visualización de datos utilizando Docker, API y bases de datos
Descripción de la actividad
Se adjunta el archivo dash-mysql.zip, que contiene un proyecto de ejemplo para la visualización de datos provenientes de sensores instalados en un campo experimental.

El proyecto utiliza Docker Compose mediante el archivo compose.yaml para configurar y ejecutar dos contenedores:

Contenedor de visualización: aloja una aplicación desarrollada en Python utilizando Dash, que permite consultar y visualizar los datos mediante gráficos interactivos.

Contenedor de base de datos: utiliza MySQL para almacenar y administrar la información obtenida de los sensores.

Adicionalmente, se proporciona el archivo Instrucciones_Dash_MySQL_Docker.txt, que incluye los comandos necesarios para ejecutar el proyecto, la configuración de los contenedores, las pruebas de conexión y el código fuente completo.

Actividad a desarrollar
Tomando como referencia el proyecto proporcionado, deberán diseñar y desarrollar un prototipo funcional basado en una arquitectura de al menos dos contenedores Docker, que permita realizar lo siguiente:

Obtención de datos: consumir información proveniente de una fuente externa mediante una API (Contenedor API-Ubuntu). La temática y la fuente de información son de libre elección.

Almacenamiento de información: guardar los datos obtenidos en una base de datos, utilizando MySQL, PostgreSQL, MongoDB o cualquier otro sistema gestor de bases de datos (DBMS) (Contenedor BD).

Visualización de datos: desarrollar una aplicación que permita consultar y representar gráficamente la información almacenada. Se sugiere utilizar Python con Dash (Contenedor Python-Dash), aunque podrán emplear otras tecnologías.

Contenerización: implementar los componentes del proyecto mediante Docker, utilizando al menos un contenedor para la base de datos y otro para la aplicación de visualización.

Integración: garantizar la comunicación entre los contenedores y comprobar el funcionamiento completo del flujo de información, desde la consulta a la API hasta su visualización.

Entregable
Presentación y demostración del prototipo en clase.

Cada alumno deberá exponer brevemente:

La problemática o necesidad que busca atender el proyecto.

La API seleccionada y el tipo de información que proporciona.

La arquitectura de la solución y la función de cada contenedor.

El diseño de la base de datos utilizada.

Una demostración del funcionamiento del prototipo, mostrando la obtención, el almacenamiento y la visualización de los datos.

Importante: El proyecto proporcionado es únicamente una referencia. Se espera que se proponga un caso de uso propio y aplique los conceptos de Docker, consumo de API, almacenamiento y visualización de datos en una solución integrada y funcional.
